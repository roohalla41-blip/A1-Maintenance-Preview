# حساب صراف — محیط آزمایشی مستقل

این مخزن محیط آزمایشی مستقل برای تکمیل و بررسی ساختار برنامه است.

## مرزهای ایمنی

- این محیط در وضعیت فعلی **بدون اتصال به هرگونه Supabase یا پایگاه‌دادهٔ راه دور** اجرا می‌شود.
- فایل `public/runtime-config.js` باید به شکل زیر باقی بماند:
  `{ url: null, key: null, previewOnly: true }`
- داده‌های آزمایشی فقط در مرورگر و فضای محلی همان محیط نگهداری می‌شوند؛ این داده‌ها اطلاعات واقعی کاربران نیستند.
- اتصال به Supabase، افزودن کلید یا نشانی پایگاه‌داده، و فعال‌سازی احراز هویت راه دور ممنوع است مگر با اجازهٔ صریح و جداگانه.
- مخزن، شاخه‌ها، تنظیمات و داده‌های نسخهٔ زندهٔ A1 خارج از محدودهٔ این کار هستند.
- هیچ کلید محرمانه، رمز، کلید service-role یا دادهٔ واقعی کاربر نباید وارد مخزن شود.

## وضعیت کار

- شاخهٔ کاری: `a1-structure-copy`
- تمرکز فعلی: تکمیل و ممیزی ساختار نقش‌ها، سطوح دسترسی، منوها، ماژول‌های حسابداری و گردش‌کارها.
- ماژول‌هایی که هنوز تکمیل یا آزمون نشده‌اند باید با وضعیت «در حال تکمیل» مشخص بمانند.
- تا پایان تکمیل ساختار و تأیید جداگانه، بیلد، انتشار و استقرار جدید انجام نمی‌شود.

## نقشه محصول

تصمیم‌های مربوط به هویت رسمی «حساب صراف / Hesab Sarraf»، بازارهای اولیهٔ افغانستان و ایران، معماری چندکشوری و چندارزی، زبان و شماره تلفن، صندوق اصلی، اشتراک، قیمت‌گذاری دلاری، پرداخت‌های چندمسیره و پنل مدیریت جهانی در سند زیر ثبت شده‌اند:

- [نقشه محصول و تصمیم‌های بین‌المللی](PRODUCT-STRATEGY.md)

این سند نقشهٔ ساختاری است؛ فعال‌سازی پرداخت، پیامک، نرخ زنده یا اتصال پایگاه‌داده در محیط Preview را مجاز نمی‌کند.

## اجرای محلی

پس از نصب وابستگی‌ها:
`npm run dev`

برای بررسی قراردادهای ساختاری:
`npm run test:contracts`

برای ساخت خروجی:
`npm run build`

اجرای دستورهای ساخت یا انتشار فقط پس از اجازهٔ جداگانه انجام می‌شود.
